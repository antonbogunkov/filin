# Filin Page - Senior System Administrator Visit Card

A professional, single-page website visit card for a senior system administrator, featuring an animated Eurasian eagle-owl mascot with network infrastructure elements.

## Features

- **Multi-language Support**: English, Russian, and Tatar
- **Professional Design**: Modern, responsive layout with dark/light theme toggle
- **Animated Owl Mascot**: CSS-based Eurasian eagle-owl with network elements
- **Interactive Elements**: Parallax effects, animated skill bars, interactive timeline
- **Single HTML File**: All CSS and JavaScript embedded, all libraries from CDNs
- **W3C Valid**: Semantic HTML5 structure

## Technologies

- HTML5
- CSS3 (with animations and glassmorphism effects)
- Vanilla JavaScript
- Font Awesome (CDN)
- Google Fonts (Inter)

## GitHub Pages Deployment

This repository is ready for GitHub Pages deployment. The `index.html` file is in the root directory.

### Setup Instructions

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Choose "main" branch and "/ (root)" folder
5. Click "Save"

Your site will be available at: `https://antonbogunkov.github.io/filin/`

## Local Development

Simply open `index.html` in any modern web browser. No build process or dependencies required.
